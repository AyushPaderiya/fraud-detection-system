Fraud Detection System

End-to-end ML pipeline for suspicious transaction monitoring
Real-time scoring API
PR‑AUC optimized · XGBoost / LightGBM / Random Forest

Detect high‑risk payments in real time.

Use the offline pipeline to ingest data, engineer features, train multiple models, and select the best one using PR‑AUC. Then expose a simple API to score live transactions.

Dataset: PaySim (simulated mobile money)
Latency: < 100 ms per transaction
Targets: FRAUD vs LEGITIMATE
①
Build & evaluate models offline.
Train Logistic Regression, Gradient Boosting, LightGBM, XGBoost, and Random Forest; compare on PR‑AUC and business KPIs.
②
Serve predictions through a web form.
Send a single transaction through the UI and instantly see the model’s classification with explanations.
③
Extend to batch & APIs.
Score CSV files for back‑testing or connect this service to upstream payment systems.
